# 识己 · 底色

一款免费、公开的自我观察 H5。用户填写公历出生信息、真太阳时辰与三项现实选择后，即时制作网页版底色报告；完成需求调研后，可保存一张带独立二维码区域的长图。

## 隐私说明

出生信息与选择仅保存在当前浏览器会话中。报告在浏览器内制作，不上传至本项目的服务器，也不要求登录 GPT。

## 正式接入问卷星

构建时设置 `NEXT_PUBLIC_WJX_URL` 为问卷星地址，并将问卷提交后的跳转地址设置为：

`https://yukinliu.github.io/shiji-base-tone/?survey=done`
